SyncGuard — Detector Evidence & Spatial Layer

Interactive companion to the pitch deck. GNSS spoofing/jamming/meaconing detection for 4G/5G base-station timing infrastructure, evaluated on the real Jammertest 2024 (Zenodo) dataset, mapped onto real ASEAN telecom tower locations.

REAL — Jammertest 2024 GNSS recordings, 136 Telkomsel tower sites (Kubu Raya / Pontianak, Indonesia), RandomForest detector evidence
SIMULATED — offline map: spoofing epicenter, distance-decay severity, spread over time, priority ranking
LIVE — replay feed: real detector scoring per event, real distance-weighted correlation; only the tower each event is attributed to is SIMULATED (round-robin, no per-tower dataset exists)
Live — requires the SyncGuard API running (api/main.py)

Live replay feed

Streams syncguard_features.parquet row-by-row through the real, trained detector via the FastAPI service's asyncio replay loop. Each event's probability and severity are real model output, scored live, not pre-computed. Each event's tower attribution is SIMULATED (deterministic round-robin over the 136 real sites — the underlying dataset is a single receiver, so there's no real per-tower mapping to use); the correlation score is a real distance-weighted aggregate of other real towers' actual recent severities in this session, computed fresh each time — see api/spatial.py.

Offline snapshot — simulated spatial layer, on real tower coordinates

Spatial anomaly severity map (static snapshot, from build_spatial_simulation.py)

Marker positions are the 136 real Telkomsel base-station coordinates. Marker color/size (severity), the blue epicenter star, and the spread over time are a documented simulation — no public dataset of real ASEAN base-station GNSS timing under spoofing exists, so this distance-decay spread stands in for "nearby infrastructure sharing correlated timing anomalies." Severity is anchored to the real detector's own predict_proba() range: floor 0.430 (median proba on real held-out clean rows) to ceiling 0.993 (90th-percentile proba on real held-out attack rows) — not invented numbers.
